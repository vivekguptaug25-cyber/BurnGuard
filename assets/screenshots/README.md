# Project Screenshots

Store the important screenshots and photos of your project in this folder.

## Recommended Screenshots

- `01-input-form.png` - Multi-step sequential reading telemetry input screen.
- `02-dashboard-overview.png` - Main BurnGuard analytics dashboard showing risk gauges.
- `03-telemetry-trends.png` - Interactive Recharts trend curves ($T_1$ to $T_5$ for Temperature, Voltage, Power, Current).
- `04-root-cause-analysis.png` - Physical failure diagnosis and parameter alert status.
- `05-ai-engineering-report.png` - Groq Llama-3.3 AI semiconductor reliability report.

## Naming Convention

Use clear names such as:
- `01-input-form.png`
- `02-dashboard.png`
- `03-trends.png`
- `04-ai-report.png`

Do not upload screenshots containing passwords, API keys, tokens, or personal credentials.

## Adding Screenshots to Main README

You can display screenshots in the main `README.md` using relative paths:

```md
![BurnGuard Dashboard](assets/screenshots/02-dashboard.png)
```
